    Клиентский софт и программная экосистема MeshCore (MCOa, MeshCore App, Reticulum)¶

    Для комфортного взаимодействия с децентрализованной сетью радиомодемов MeshCore используются мобильные, веб- и десктопные клиентские приложения, связывающиеся с нодами по Bluetooth Low Energy (BLE), Wi-Fi или USB-Serial. В сообществе СКФО сформировалась развитая программная инфраструктура.

    1. Флагманский клиент: MeshCore Open Advanced (MCOa)¶

    Стандартом де-факто для участников региональной сети стало мобильное приложение MeshCore Open Advanced (MCOa) (форк под авторством Антона Уральского и HDDen, репозиторий GitHub HDDen/meshcore-open, активные релизы веток 9.5.1-mod-1.8.x – 9.5.1-mod-1.11.x).

    Ключевые возможности MCOa:¶

    1. BLE Proxy (Multi-Connect):
    2. Устраняет аппаратное ограничение радиомодулей: большинство микроконтроллеров nRF52/ESP32 могут держать физическое соединение по Bluetooth только с одним смартфоном.
    3. Телефон с запущенным MCOa подключается к ноде по физическому BLE и выступает шлюзом (прокси), позволяя другим смартфонам семьи или группы подключаться к нему по виртуальному BLE-мосту и пользоваться одной общей рацией.
    4. Продвинутое сжатие и медиаданные (MCMP / MCOtxt / MCOimg):
    5. Внедрен легковесный алгоритм компрессии текста MCMP, уменьшающий длину длинных сообщений в радиопакете до 40%.
    6. Поддержка плейсхолдеров изображений MCOimg и анимаций GIF со встроенным кэшированием до 200 МБ на диске смартфона (предотвращает повторную выкачку медиа через медленный эфир).
    7. Встроенный модуль Wardrive (Вардрайвинг):
    8. Приложение использует GPS смартфона и RSSI/SNR принятых пакетов LoRa для построения карты реального радиопокрытия.
    9. Интеграция с skmesh.ru: Ввод персонального API-токена, настройка интервала сканирования (10 с для поездок на авто/велосипеде, 20–30 с для пеших прогулок). Данные автоматически загружаются на сервер и формируют тепловую карту покрытия края.

    2. Мобильные клиенты MeshCore и веб-интерфейсы¶

    2.1. Платформа Android: MeshCore Android Client¶

    • Официальное клиентское приложение MeshCore (разработчик Liam Cottle): Google Play Store.
    • Поддержка подключения к узлам по BLE, USB-Serial и TCP.
    • Полная интеграция с сервисом RoomServer (BBS): автоматическая синхронизация пропущенных сообщений при появлении в радиусе слышимости сервера, поддержка публичных каналов и приватных зашифрованных комнат.
    • Встроенный монитор качества радиолинии (LQI, SNR, RSSI).

    2.2. Платформа iOS: MeshCore Mobile Client¶

    • Официальный клиент для iPhone / iPad: Apple App Store и программа бета-тестирования через TestFlight.
    • Поддержка протокола MeshCore по Bluetooth Low Energy (BLE), чат, просмотр карты и статусов узлов.

    2.3. Веб-интерфейсы (Web Bluetooth / Web Serial)¶

    • Региональный веб-клиент skmesh.ru и портал meshcoretel.ru: прямое подключение к ноде прямо из браузера Chromium (Chrome / Edge / Yandex).
    • Официальный глобальный веб-клиент app.meshcore.nz: оперативная отправка сообщений, просмотр топологии сети, карты нод и статусов ретрансляторов без установки сторонних программ.

    2.4. Тактическая навигация и картография¶

    • Сообщество использует интеграцию радиомодемов со связным комплексом CivTAK (Civilian Team Awareness Kit) для обмена координатами, геометками и маркерами зон в походах и поисковых операциях при полном отсутствии сотовой связи.

    3. Альтернативный криптографический стек: Reticulum (RNode)¶

    Группа радиоинженеров и энтузиастов сообщества (Доктор Z и др.) ведет исследовательские работы и практическое тестирование альтернативного независимого криптографического стека Reticulum Network Stack:

    Компоненты экосистемы Reticulum:¶

    1. Прошивка RNode / RTNode:
    2. Превращает типовые платы LoRa (Heltec V3/V4, T-Beam) в универсальные аппаратные радиомодемы для стека Reticulum.
    3. Работает на уровне сырых кадров канального интерфейса с адаптивной скоростью передачи.
    4. Приложение Sideband:
    5. Полнофункциональный мобильный и десктопный интерфейс для связи через сеть Reticulum.
    6. Поддерживает сквозное асимметричное шифрование сообщений, передачу файлов и голосовых заметок.
    7. Клиент MeshChatX:
    8. Легковесный чат-клиент, оптимизированный под медленные пакетные LoRa-радиоканалы высокой задержки.
    9. Стационарные интернет-шлюзы:
    10. Возможность бесшовного объединения нескольких радиоостровов через глобальный Reticulum-оверлей поверх интернета (I2P, Tor, TCP).
